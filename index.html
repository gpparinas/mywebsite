2FA Roll-out Blocked by Endpoint-Security

Nearsol Philippines • 2023

Problem:

500 endpoints stuck at Windows log-in after new 2FA agent deployment; keyboards/mice unresponsive, preventing supervisor-approval flow.

Action:
  • Reconfig PowerShell script provided to remove broken 2FA agent remotely & added domain GPO for PH region.
  • Joined vendor + security bridge call; live-demoed root-cause (Sentinel deleting keyboard-driver signature bound to 2FA agent).
  • Co-ordinated whitelist update in Sentinel while vendor patched agent.
Result:

Reduced affected devices from 500 → 0 in 36 h; prevented re-occurrence by pushing updated agent + driver allow-list to 1400 endpoints.

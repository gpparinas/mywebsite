# Gabriel Pariñas — IT Infrastructure & Support Portfolio

Live site: [https://gpparinas.github.io/mywebsite](https://gpparinas.github.io/mywebsite)

A single-page portfolio website for Gabriel Philip Pariñas, showcasing IT infrastructure, systems administration, networking, monitoring, certifications, and professional experience.

## What's inside

| File | Purpose |
|------|---------|
| `index.html` | Main single-page portfolio layout and content |
| `style.css` | Custom design system, responsive layout, dark mode styling, cards, timeline, and section styling |
| `script.js` | Theme toggle, mobile navigation, smooth scrolling, fade-in effects, and active nav highlighting |
| `photo.png` | Professional headshot shown in the hero section |
| `resume.pdf` | Downloadable résumé for recruiters and hiring managers |

## Features

- Dashboard-style layout: sticky profile sidebar, bold headline, scrolling tools strip, and a bento grid of cards linking to each section
- Custom responsive single-page portfolio (sidebar becomes a slide-out drawer on mobile)
- Light and dark mode
- Sidebar navigation with active section highlighting
- Smooth scrolling and fade-in reveal animations
- Skills, tools, experience timeline, certifications, and contact sections
- Resume download and external profile links
- Accessible structure with skip link, semantic sections, and focus states
- GitHub Pages deployment with no build step required

## Local preview

```bash
git clone https://github.com/gpparinas/mywebsite.git
cd mywebsite
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000)

## Deployment

This site is deployed with GitHub Pages from the repository branch.

## Updating assets

To update the profile photo or résumé, replace these files with the same filenames:

- `photo.png`
- `resume.pdf`

GitHub Pages will publish the updated versions after the next commit.
